The storage template the server's disk is cloned from. The list holds the public templates provided by UpCloud and, marked Custom, the templates of your own account together with the zone they are stored in. A custom image can only be used for servers in its own zone.

The image has to be a Linux system that is reachable over SSH. Java must be installed for the agent to start: either as part of a custom image or by the initialization script.

To use a custom image, set up a server the way you need it, stop it and create a template from its storage in the UpCloud control panel or with the API. Storages and backups that have not been turned into a template are not listed. Neither are templates that the account of the API credentials has no access to.
